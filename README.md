# Bricko for Android

Build in 3D with studded bricks, turn pictures into brick models, take on build tasks, play music and export your builds as 3D files.

## Install on your phone
Download the latest app: **https://github.com/Krmj33t/bricko/releases/latest/download/Bricko.apk**

Open the downloaded file to install it. The first time, Android asks you to allow installing apps from your browser or Files app.

## How it's built
Every push to `main` builds the app with GitHub Actions and publishes it as the latest release.
To install a newer version, uninstall the old one first.

The app itself is in `www/index.html`.
